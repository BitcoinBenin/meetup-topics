## ✅ Comment bien se préparer

Cet atelier est une discussion ouverte pour tous ceux qui se posent la question : **Comment utiliser Bitcoin dans mon activité professionnelle ?** 

Que vous soyez entrepreneur, free-lance, commerçant, étudiant ou particulier, vous êtes bienvenu(e) !

### Préparation recommandée

Pour profiter au maximum de l'événement, nous vous conseillons de :

- Avoir un smartphone ou un ordinateur avec une bonne connexion internet
- Préparer toutes vos questions sur l'utilité du Bitcoin
- Préparer une explication de votre activité professionnelle pour discuter de la meilleure façon d'intégrer Bitcoin
